# Market Monitor

A static, public GitHub Pages dashboard with searchable watchlists and TradingView charts. Includes 41 instruments in the primary Favorites list and 14 in the older list, retrieved November 13, 2026.

## Publishing

In **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, and save.

Site: https://tflchina.github.io/market-monitor/

## Limitations

This is a watchlist snapshot, not an automatic brokerage synchronization. Quotes may be delayed or unavailable depending on the market-data provider. This site has no brokerage credentials, holdings, or trading functions.
